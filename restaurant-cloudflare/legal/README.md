# Dokumenty prawne do przygotowania

Obecny regulamin i polityka prywatności opisują Restaumatic jako procesora i element sklepu internetowego. Nie należy ich kopiować do nowego rozwiązania. Nowy komplet powinien uwzględniać co najmniej: dane przedsiębiorcy, model zawarcia umowy przez Google Forms, sposób potwierdzania zamówienia, ceny i opłaty, płatności, dostawę/odbiór, anulowanie, reklamacje, dane osobowe, Google i Cloudflare jako dostawców oraz retencję odpowiedzi formularza;
